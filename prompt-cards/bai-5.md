Model AI: **Mặc định** và **Mạnh**. Mỗi prompt ghi rõ dùng model nào; đổi model ở ô chọn phía dưới khung chat của Kilo Code trước khi gửi.

Nếu muốn làm lại từ đầu bài: `npm run bai -- 5`
